Liquid Stack

为博客与个人网站打造的完整主题

基于 Stack v4 打造的完整双语站点模板，以 Liquid Glass 为设计灵感，集成主页小组件、项目启动台、照片墙、仪表盘、评论和可视化内容后台。

开始使用 查看演示 在 GitHub 上查看 真实站点演示

Liquid Glass 视觉

半透明层次、大圆角卡片、柔和阴影与蓝灰配色贯穿整套网站。

主页小组件

个人信息、快捷卡片、世界时钟、归档、分类、标签和内容预览集中呈现。

完整双语结构

中英文共享同一套页面结构，并支持语言识别、偏好记忆与同页译文切换。

完整网站工具

启动台、照片墙、关于页面、仪表盘、评论、友链、站点地图与可视化 CMS 一应俱全。

一套完整框架

Liquid Stack 保留 Stack 原有博客基础，并补齐个人网站需要的页面与工具。替换示例数据和视觉素材即可使用，无需重新搭建结构。

写作与阅读文章、分类、搜索、目录、分享、打印和本地化日期。
项目与照片应用式项目启动台与支持替换数据的交互照片墙。
关于与个人主页带动画的个人页面，可用于网站故事、个人介绍或简历。
网站仪表盘内容统计、发布热力图、分类分布和系统状态。
内容管理经过主题化的 Sveltia CMS，可管理文章、分类、项目、照片和网站设置。
开源起步模板包含通用双语示例与可替换素材，不包含个人服务凭据。
